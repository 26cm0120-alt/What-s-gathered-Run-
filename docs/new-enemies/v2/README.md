## 素材

内蔵imagegenを使用。保存先は `Map/Assets.xcassets/` 内の `DungeonImp.imageset`（差し替え）、`ImpDefeated / GhostDefeated / CyclopsDefeated / MimicDefeated / DragonDefeated.imageset`（追加）。

小悪魔の生成指示：参照画像を32×40相当の大きなピクセル群・16色を目安とした簡素な画風へ。細かい髪・装飾・グラデーションを避け、特徴を保持。透明背景。

撃破画像の生成指示：参照キャラクターの色・衣装を保ち、床に倒れた低い横長の姿。小悪魔とドラゴンは目を閉じて伏せ、ゴーストはローブの山、サイクロプスは横倒し、ミミックは目を閉じ舌を垂らす。流血・床タイル・文字を入れず透明背景。小さなマップでも判別できる不透明な本体。
